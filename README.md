## 部署与运行说明

### 环境要求
- Node.js >= 18.0.0
- npm >= 9.0.0 或 pnpm >= 8.0.0

### 安装依赖
```bash
npm install
```

### 本地运行
```bash
# 启动前端本地开发服务器 (纯前端运行，自动加载本地 SQLite 数据库文件)
npm run dev
```
启动完成后，在浏览器中打开终端输出的本地开发服务器地址（如 `http://localhost:5173/`）即可体验完整系统。

## 招标公告全文

### 6. 摘要
兴文县水利局委托四川名哲工程项目管理有限公司，对新坝水库隔离防护网和智慧监控系统项目(二次)组织竞争性谈判，预算金额与最高限价为1,954,000.00元。采购标的为隔离防护网与智慧监控系统，合同签订之日起30日内发货，60日内完成本项目所有货物的供货及安装调试，不接受联合体投标，响应文件提交截止时间为2026年10月09日10:00。

### 7. 技术要点
- **长周界防攀爬隔离网与电子传感协同定位**：支持桩号级精细化告警联动。
- **球机热成像视频与高音广播声光智能联动**：实现涉水入侵目标秒级威慑劝离。
- **水库大坝水雨情与库水位自动化采集预警**：融合汛限水位动态比对与预报调度。
- **前端 WebAssembly sql.js 边缘极速响应体系**：零后端常驻服务器开销，离线数据本地极简持久化。

### 8. 技术创新性
- **全要素水库水务安防数字孪生一张图**：宏观掌控水质安全、库容蓄水量及周界防范态势。
- **基于统一命名空间隔离的数据主权架构**：专用数据表前缀与独立存储载体，杜绝数据交叉干扰。
